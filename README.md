# City Explorer

Mini-site de prezentare a unor destinații turistice, realizat în cadrul disciplinei Tehnologii Web.
Proiectul conține o machetă statică structurată cu HTML semantic și stilizată cu CSS modern, folosind Flexbox și CSS Grid responsiv.
Aplicația permite vizualizarea destinațiilor recomandate și planificarea unei călătorii printr-un formular dedicat[cite: 1].
